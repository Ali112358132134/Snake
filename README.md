# Snake
## This project implements the classic Snake game in C for an embedded system using a graphical LCD display and a matrix keypad for input. The program runs bare-metal (no OS) and directly interacts with hardware through memory-mapped registers.

# Key Features
## Real-time gameplay on a graphical LCD
## Keypad-controlled movement (up, down, left, right)
## Dynamic snake growth when eating apples
## Collision detection:
## Wall collisions
## Self-collisions
## Randomized apple spawning using a hardware timer
## Low-level hardware control (GPIO, SysTick, Timer)
